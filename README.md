# 🌍 Global Economic Growth Dashboard

An interactive Power BI dashboard analyzing global GDP 
trends across 262 countries from 2000 to 2024.

## 📁 Project Files
- `GDP_Dashboard.pbix` — Power BI dashboard file
- `gdp_raw.xlsx` — Original World Bank dataset
- `gdp_cleaned.xlsx` — Cleaned and merged dataset
- `Report.pdf` — Full project report

## 🔍 Key Insights
- Global average GDP growth: **3.44%**
- Average GDP per capita: **$14,910 USD**
- Countries tracked: **262**
- Highest GDP per capita: Liechtenstein, Luxembourg, Norway
- USA and China dominate global GDP share

## 📌 Data Source
World Bank Open Data — https://data.worldbank.org

## 🛠️ Tools Used
- Microsoft Power BI
- Microsoft Excel (Power Query)

## 📚 Indicators Analyzed
- GDP (current US$)
- GDP Growth Rate (annual %)
- GDP Per Capita (current US$)
- GNI Per Capita (current US$)
